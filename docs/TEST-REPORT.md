## Notes on how these tests are written

Integration tests run the real Express app, through Supertest, against a real
file-backed SQLite database - each test file gets its own in a temp directory,
so suites cannot interfere with each other or with development data. Nothing
is mocked at the HTTP or database boundary.

Two of the checks here are themselves tested, because a test that cannot fail
is worse than no test:

- the OpenAPI drift check was verified by injecting a fictional endpoint into
  the spec and a fictional route into the router, and confirming the right
  test failed each time, naming the offender
- the route-table helper that check depends on has its own test, so it cannot
  silently return an empty list and make the comparison pass vacuously
